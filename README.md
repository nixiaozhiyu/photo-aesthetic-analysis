# 照片审美拆解 Skill

帮助摄影爱好者理解一张照片为什么吸引自己，并学习如何拍出类似效果。

## 功能
- 分析构图、色彩、光线和叙事。
- 在原照片副本上标出中心线、主体位置、引导线等构图依据。
- 区分可见事实、效果解读和个人偏好推测。
- 提供对应的拍摄建议与对比练习。

## 使用
在支持本地 Skills 的 Codex 环境中，将项目文件放入个人 skills
目录下的 photo-aesthetic-analysis 文件夹。

发送照片，并输入：
请用 $photo-aesthetic-analysis 分析这张照片，并标出构图依据。

构图标注需要运行环境提供图像编辑能力。
